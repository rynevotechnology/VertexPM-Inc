## 🏗️ About VertexPM Inc.

VertexPM Inc. is a Burlington-based construction management, quality, and engineering-support company serving Southern Ontario. We support contractors, municipalities, project owners, developers, and project teams through project planning, permitting, construction, inspection, testing, documentation, and final turnover.

- **PEO Certificate of Authorization**: Professional engineering practice compliance.
- **Location & Service Area**: Burlington, Ontario — serving Southern Ontario.

## 📋 Core Services & Capabilities

1. **Construction Management**  
   Project coordination, reporting, RFI support, action tracking, document control, and construction-phase delivery support.

2. **Quality Management**  
   CQMPs, ITPs, checklists, audits, NCRs, deficiencies, red-line drawings, as-built records, and quality closeout.

3. **Building Permit Support**  
   Permit drawings, design coordination, Professional Engineer review, submission support, and municipal comments resolution.

4. **Specialized Inspection**  
   Welding inspection, weld doc review, visual inspection records, protective coating inspection, surface prep checks, and dry film thickness (DFT) checks.

5. **Owner & Municipal QA Oversight**  
   Independent quality oversight for municipalities and project owners, contractor QA/QC review, and acceptance/turnover packages.

6. **Closeout & Turnover**  
   Documentation gap review, issue closure, as-built verification, and complete turnover package reconciliation.

## 🚀 Running Locally

Open `index.html` directly in any web browser, or launch a lightweight local server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```

Open your browser to `http://localhost:8080`.
