## 🏗️ About VertexPM Inc.

VertexPM Inc. is a partner-led, field-focused construction management and quality consulting practice. From initial planning to final handover, we bring clarity, control, and engineering rigor to infrastructure and heavy civil delivery across Ontario.

### Core Capabilities
- **Construction Management**: Project controls, field supervision, scheduling, contract administration, and constructability reviews.
- **Quality Assurance & Quality Control (QA/QC)**: Comprehensive Quality Management Plans (QMPs), Inspection & Test Plans (ITPs), audit readiness, and contractor compliance.
- **Infrastructure & Heavy Civil**: Metrolinx, MTO, and municipal standards adherence for transit, bridge, roadway, and utility installations.

## 🚀 Getting Started

This repository contains the standalone modern web application for VertexPM Inc.

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari)
- Optional: Local HTTP server such as [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) or Python (`python -m http.server 3000`)

### Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/rushirpadaria2704/VertexPMInc..git
   ```
2. Open `index.html` directly in your browser or run a local server:
   ```bash
   # Using Python
   python -m http.server 8080

   # Using Node.js (npx)
   npx serve .
   ```
3. Navigate to `http://localhost:8080`.
